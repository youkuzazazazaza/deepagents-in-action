## Lite 打卡级：第一个 Deep Agent

**验证**：一个普通 Python 函数，凑齐"清晰描述 + 类型注解 + 明确返回值"三要素，就能被 Agent 当工具调用。**改**：给 `add` 补齐 docstring 和 `a: float, b: float` 注解。**结果**：Agent 没心算，忠实"点单"调 `add(12345.678, 8765.432)` = 21111.11。**解释**：docstring 就是写给 LLM 看的"说明书"。**下一步**：搬进常驻服务。

## Basic 基础级：接通完整调用链（四件套对应代码 · 展开版）

**验证**：HTTP 常驻服务的「请求 → 执行 → 返回」全链路。**改**：`langgraph.json` 注册 graph、`.env` 配 key。**结果**：客户端发请求 → 服务端 Agent 调 add → 结果落盘 `basic_trace.json`。

### ① 模型（Model）——大脑，只决策不干活

**大白话**：Agent 的决策核心。它读对话、看工具说明书（docstring）、决定"点单"。**代码位置**：`.env`（源头）→ `src/research_deepagent/agent.py`（装配线）

```python
# .env 三行 = 模型的"身份证"（换模型只改这里，05 篇实操过：GLM ↔ DeepSeek）
AGENTSEEK_MODEL=deepseek-flash                # 叫什么名字
OPENAI_API_BASE=https://api.deepseek.com/v1   # 住在哪（哪家 API 端点）
OPENAI_API_KEY=sk-****                        # 门禁卡（key）

# agent.py 装配线（行号是实据）：
:30  load_dotenv()                       # 把 .env 读进环境变量
:71  os.getenv("AGENTSEEK_MODEL")        # 取模型名（兜底链 DEEPAGENTS_MODEL→BUB_MODEL→DeepSeek-V3.2）
:77  MODEL_PROVIDER 默认 "openai"        # 走 OpenAI 兼容协议
:137 if MODEL_PROVIDER == "openai":      # openai 分支（:137-147）
:139     kwargs["api_key"]  = OPENAI_API_KEY     # ← 门禁卡装上
:141     kwargs["base_url"] = OPENAI_API_BASE    # ← GLM/DS 随便切的机关在这行
:159 model = init_chat_model(**kwargs)   # 一行造出大脑
:173 graph = build_graph(model)          # 大脑装进 graph
```

**一句话**：`.env` 是身份证，`init_chat_model`（:159）是装配线——graph 结构一行不动，换 `.env` 就是换发动机。

### ② 工具（Tools）——手脚，只干活不决策

**大白话**：模型发指令不干活，`add` 才是真算数的。**代码位置**：定义在 `src/research_deepagent/tools.py`，挂载在 `agent.py`

```python
# tools.py:125-138 —— 你的工具本体
@tool(parse_docstring=True)             # ← 装饰器：普通函数变 Agent 工具
def add(a: float, b: float) -> float:   # ← 类型注解 → 自动生成参数 schema
    """Add two numbers precisely...     # ← docstring → 模型读的"使用说明书"
    Use this tool for any arithmetic addition instead of computing yourself."""
    return a + b                        # ← 真正的执行体

# agent.py:28   from research_deepagent.tools import add, tavily_search, think_tool
# agent.py:166  tools=[tavily_search, think_tool, add]    # ← 挂上工具 belt
# agent.py:130  子 agent 也挂了 tavily_search/think_tool（huge 自救那个子线程）
```

**一句话**：定义在 `tools.py:125`、挂载在 `agent.py:166`；schema 在执行前把关——04 篇 400 个 9 被 `a: float` 拒收，防线就是这层类型注解。

### ③ Middleware——护航员，模型之外的框架能力

**大白话**：不参与决策，但让 Agent 更能干、更可控的"外挂装备"。本项目一件显式 + 两件隐形：

```python
# agent.py:20  from langchain.agents.middleware import TodoListMiddleware
# agent.py:165 middleware=[TodoListMiddleware()]          # ← 显式挂载
# agent.py:169 checkpointer=checkpointer（参数传入，api 层注入）# ← 隐形装备
```

| 装备 | 在哪 | 干什么 | 你见过它干活吗 |
|---|---|---|---|
| **TodoListMiddleware** | agent.py:165 | 给模型一个 write_todos 工具，干复杂活前先列计划 | ✅ huge 自救 27 条消息里 Agent 给自己列任务清单 |
| **checkpointer** | agent.py:169 | 每步消息存档，thread 断点续聊 | ✅ threads/search 里能翻到完整 17 条消息历史 |
| **LangSmith tracing** | `.env` 的 LANGCHAIN_TRACING_* 变量 | 每步耗时/token 上报云端 | ✅ 03 篇网页上那棵 trace 树，零代码 |

**一句话**：装备栏就是 `create_deep_agent(middleware=[...])`（:163-170），往列表里加就是加装备。

### ④ Backend——餐厅本体，让一切常驻在线

**大白话**：Lite 版是"一次性厨师"（脚本跑完就散伙），Backend 是"开餐厅"——服务常驻 2024 端口，谁随时来都能点单。**代码位置**：`langgraph.json`（总装配单）+ `agentseek` 命令（服务员团队）

```json
// langgraph.json —— 项目的总装配单（注意两个名字别搞混）
{ "graphs": { "research": "./src/research_deepagent/agent.py:graph" },
              ↑键名=research 供客户端按名点单    ↑冒号后=变量名，必须叫 graph（agent.py:173 那个变量，当年踩的坑在这）
  "env": "./.env" }
```

进程树（`ps aux` 实据，四层）：

```
agentseek dev                              # 总管：开机预检（uv/node/配置），预检 fail 直接拒启（05 篇踩过）
└─ agentseek-api dev --port 2024           # HTTP 服务：收请求、管 threads、给 graph 注入 checkpointer
   └─ uvicorn …runtime_entrypoint          # 真正的 Web 服务器（你 curl 的 2024 就是它）
frontend/（npm run dev）                    # 网页聊天界面（独立进程）
存储：threads/checkpoints 落 OceanBase（.env 的 OCEANBASE_DB_NAME）
```

**一句话**：`langgraph.json` 把 `agent.py` 里的 `graph` 变量注册成名叫 `research` 的服务；`agentseek dev` 把它跑成常驻 HTTP——run_basic.py 打的 2024 端口就是它。

## Advanced 挑战级：边界输入对撞（冲优秀）

三发炮弹：**normal** 满分交卷；**empty** 不瞎编数字——反问用户或翻盘找证据（两轮路径不同，底线相同）；**huge** 400 个 9 在执行前被 `a: float` 的 schema 拒收（超出 float64 上限），Agent spawn 子线程自救 27 条消息，但最终**誊写长数字仍翻车**（两轮错法还不同：621 位 / 10^258）。**结论**：第一道防线是类型系统不是代码逻辑；LLM 结构性地抄不动几百位长数。**证据**：`adv_*.json` + LangSmith trace。

## 学有余力：双模型对撞

`.env` 三行 + 重启 = 换脑（编排零改动，这就是框架红利）。**对撞结果**：normal 两家都满分，DeepSeek-V4.1-Flash 快 2.7 倍（3.6s vs 9.7s）；schema 拒收与模型无关——防御长在框架层。**结论**：乖题比不出高下，边界题才见"性格"；选模型要测它的底线行为。
