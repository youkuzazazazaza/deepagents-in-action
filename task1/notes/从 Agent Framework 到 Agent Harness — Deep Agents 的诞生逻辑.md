## Agent开发的三个层次

**一、底层：Agent Runtime（运行时层）- LangGraph - Agent世界的操作系统**

基座，解决”Agent 怎么可靠运行“

- 持久化执行：断点恢复
- 流式输出：实时看到思考和操作过程
- 人机协作：关键步骤停止，等待人工审批
- 状态管理：持久会话，跨会话保存上下文



**二、中间层：Agent Framework（框架层)-LangChain**

​	模型抽象、工具接口、Agent循环、中间件

​	构建在LangGraph之上



**三、上层：Agent Harness（工具层）- Deep Agents - Agent loop**

一部分默认装配，一部分按需配置：

- 虚拟文件系统
- 任务规划：拆解任务
- 子Agent委派
- Skills：操作手册
- 上下文管理：将长上下文进行总结、摘要、卸载到文件
- 记忆：加载指定的记忆文件

本质职责：

- 循环驱动
- 工具装配与管理
- 上下文工程
- 状态与记忆
- 权限与安全
